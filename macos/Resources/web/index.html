    Cihazda nasıl ayarlanır
    PS5
    Ayarlar › Ağ › Ayarlar › İnternet bağlantısını kur › bağlantın › Gelişmiş ayarlar: IP ayarları Manuel (yukarıdaki değerler), MTU Manuel, Proxy kullanma.
    PS4
    Ayarlar › Ağ › İnternet bağlantısını kur › Özel: IP Manuel, DNS Manuel, MTU Manuel, Proxy kullanma.
    Xbox
    Ayarlar › Genel › Ağ ayarları › Gelişmiş ayarlar: IP ayarları El ile, DNS El ile.
    Switch
    Sistem ayarları › İnternet › ağın › Ayarı değiştir: IP Manuel, DNS Manuel, MTU.
    TV
    Ağ ayarları › IP ayarları Statik/Manuel (aynı değerler).

    Mac açık, Zapret çalışıyor ve paylaşım açık olmalı; yoksa cihaz internete çıkamaz. Bilgisayarsız oynarken cihazda IP'yi Otomatik'e döndür.
