# macOS Aşama 0–1 (iskelet + motor ve engel aşma) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mac'te açılan, Windows'taki arayüzü birebir gösteren ve "Başlat" ile tpws (SOCKS) + sistem SOCKS proxy'si üzerinden Discord'u açan ilk uygulama; sahada (MacBook Air 2018, Monterey) denenebilir zip.

**Architecture:** SwiftPM paketi `macos/`: saf mantık `ZapretCore` (birim testli), uygulama `RedRiveRRZapret` (AppKit + WKWebView, `ui/web` aynı dosyalar, `window.chrome.webview` taklidi), root yardımcı `zwt-helper` (Unix soketi, yalnız sabit komutlar). Derleme/test yalnız GitHub Actions macOS sunucusunda.

**Tech Stack:** Swift 5.9, AppKit, WebKit, XCTest, `networksetup`, `launchctl`, zapret v72.13 `binaries/mac64/tpws`, GitHub Actions `macos-14`.

**Spec:** `docs/superpowers/specs/2026-10-27-macos-design.md` (Bölüm 7.1, 7.2, 7.3, 7.4, 7.6a, 7.7; Aşama 0 ve 1)

## Global Constraints

- En düşük macOS 12 (`.macOS(.v12)`); universal derleme (`--arch arm64 --arch x86_64`).
- Arayüz kaynağı tek: repodaki `ui/web/` dosyaları pakete kopyalanır; Mac'e özel arayüz dosyası yok. Windows'ta davranış değişmez (Windows `platform` mesajı göndermez).
- Mesaj sözleşmesi `ui/web/uygulama.js` başındaki listeyle aynı (alan adları birebir).
- Kullanıcıya görünen metinler Türkçe; durum metinleri `lib/WebState.au3` `_WebStatusParts` ile aynı.
- Sistem ayarı geri alınabilir olmalı: proxy önceki hâline döner (durdur, uygulama kapanınca, uygulama çökünce).
- Yönetici şifresi yalnız yardımcı kurulurken bir kez.
- Yardımcı yalnız sabit komutlar; proxy adresi her zaman `127.0.0.1`, port 1024–65535; rastgele yol/komut çalıştırmaz; yardımcı ikilisi root'a ait konumda (`/Library/PrivilegedHelperTools/`).
- Kişisel veri yok (repo, paket); `scripts/check.ps1` geçer. AI atfı yok.
- Testler bu Windows bilgisayarda koşamaz: her görevin "testi çalıştır" adımı = push + `gh run watch` (iş akışı `macos.yml`).

## Review Focus

1. Uygulama çöker/zorla kapatılırken proxy açıksa Mac'in interneti kesilir → yardımcı uygulama PID'ini izler, PID ölünce proxy'yi geri alır (Task 4 testi `testProxyRestoredWhenOwnerDies`).
2. Birden çok ağ hizmeti (Wi-Fi + Ethernet + VPN, devre dışı `*` ile işaretli) → yalnız etkinlere uygulanır, her biri kendi eski hâline döner (Task 3 testleri).
3. Kullanıcının zaten bir SOCKS proxy'si varsa → yedeklenip aynen geri yüklenir (Task 3 `testRestoreKeepsUserProxy`).
4. tpws portu meşgul ya da tpws hemen kapanırsa → proxy hiç açılmaz, sayfada hata (Task 5 `testStartFailsWhenPortBusy`).
5. Zip'ten açılan tpws çalıştırılamaz (çalıştırma izni/imza düşmüş) → build betiği `codesign -v` ve çalıştırma iznini doğrular (Task 6).
